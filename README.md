# Roast the Smart Fridge: One Line, Best Laugh Wins

One line, 148 characters, roasting the smart fridge as the house's silent witness: it has seen every 3am ice cream, every breakfast lie, and every salad performance — yet it still can't keep lettuce alive.

`main.py` writes the entry deterministically to `<OUTPUT_DIR>/entry.txt` (default `/output`) and validates it (1–160 characters, single line, UTF-8, not whitespace-only).
